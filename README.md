# Redoubt

A first-person redcoat battle for four objectives: the Village, the Fort, the Bridge and the Hill.
You are a private in a British regiment. Capture and hold objectives to earn battlefield points; the first army to 250 wins.

**Play:** open `index.html` in Chrome, Edge or Safari (needs internet to load Three.js).

Controls: WASD move · Shift run · Space jump · Click fire · R reload · F / Right-click bayonet.
